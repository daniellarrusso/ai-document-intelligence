# Review

Inspect `git status`, `git diff`, relevant source and tests.

Review for correctness, requirements, architecture, .NET/Angular quality, error handling, security, performance, tests, maintainability, API compatibility and accidental changes.

Report findings as:
- BLOCKER
- IMPORTANT
- SUGGESTION

For each finding give file/line, problem, why it matters and a concrete recommendation. Do not manufacture findings.

Finish with validation actually performed and remaining risks. Do not give a numeric score or overall rating.
