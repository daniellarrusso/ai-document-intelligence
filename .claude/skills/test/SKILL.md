# Test

Inspect changed code and existing tests first. Identify the project's actual test commands.

Add or update focused tests for changed behaviour. Run the narrowest relevant tests first, then broader validation where useful. Report exactly what was run and the result.

Do not write tests solely for coverage numbers, test private implementation details, or weaken tests to make them pass.
