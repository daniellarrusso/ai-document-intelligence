# Implement

Before editing:
1. Inspect relevant code, interfaces, tests and configuration.
2. Identify existing architectural patterns.
3. Consider edge cases, security and backwards compatibility.
4. Briefly state the approach.

Then implement the smallest appropriate change, add/update tests, run validation and inspect the final diff.

Do not refactor unrelated code, add speculative features, or add dependencies without justification.

Finish with changed files, behaviour, tests, commands/results and remaining concerns.
